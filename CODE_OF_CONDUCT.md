# Code of Conduct

We follow the spirit of the [Contributor Covenant 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

- Be respectful and constructive; critique code and physics, not people.
- Welcome newcomers and different backgrounds (space weather, power engineering, submarine cable, software).
- Harassment, discrimination and personal attacks are not accepted.
- Report concerns to the maintainer (Shibaji Chakraborty). Maintainers may remove contributions or contributors that break these rules.
