# lightning (planned)

Documented stubs only: stroke parameters (IEC 62305), statistics, Monte Carlo, coupling and protection staging. They raise `NotImplementedYet` until the standard's values are in hand; deferred by decision.

Status: planned. Chapter 15 (lightning).

**Read first:** [Lightning](../chapters/15_lightning.md)

| Module | What it does |
|---|---|
| [`coupling`](#bolts.lightning.coupling) | Lightning: coupling of a strike into the station earth, the land cable and the line. Planned for v0.2; see ROADMAP.md. *(stub)* |
| [`monte_carlo`](#bolts.lightning.monte_carlo) | Lightning: Monte Carlo of strikes with exceedance curves and return periods. Planned for v0.4; see ROADMAP.md. *(stub)* |
| [`protection_stage`](#bolts.lightning.protection_stage) | Lightning: surge-protection staging between the land cable, the beach joint and the PFE / repeater. Planned for v0.4; see ROADMAP.md. *(stub)* |
| [`statistics`](#bolts.lightning.statistics) | Lightning: lightning statistics (ground flash density, peak-current distribution; to be verified from CIGRE / IEEE). Planned for v0.4; see ROADMAP.md. *(stub)* |
| [`stroke_parameters`](#bolts.lightning.stroke_parameters) | Lightning: stroke parameters (peak current, front, tail, multiplicity). Planned for v0.2; see ROADMAP.md. *(stub)* |
