# 11. Glossary

| Term | Meaning | Where |
|---|---|---|
| **BU** (branching unit) | a node where a branch joins the trunk and the power feed can be reconfigured | [14](14_branching_units.md) |
| **Chainage** | distance along the cable route, km | [01](01_storm_to_volts.md) |
| **Constant current** | a supply that changes its voltage to keep the current fixed | [02](02_power_feeding.md) |
| **EMF** | electromotive force: the voltage induced along a conductor | [01](01_storm_to_volts.md) |
| **ES / SES / UAS** | errored, severely errored and unavailable seconds | [05](05_terminal_and_traffic.md) |
| **GMD** | geomagnetic disturbance (space weather) | [01](01_storm_to_volts.md) |
| **GPR** | ground potential rise: the potential of an earth electrode carrying current | [16](16_earthing_damage.md) |
| **Headroom** | voltage the PFE can still add beyond what it needs now | [02](02_power_feeding.md) |
| **High-pass** | the regulator's response: slow changes absorbed, fast ones pass | [03](03_circuit_model.md) |
| **Jump bound** | `dV / R_loop` for the largest sample-to-sample change, the worst case if the jump were instantaneous | [03](03_circuit_model.md) |
| **MNA** | modified nodal analysis | [03](03_circuit_model.md) |
| **Net voltage** | the end-to-end induced voltage after the sea-earth potentials | [01](01_storm_to_volts.md) |
| **OSNR / Q / margin** | optical signal-to-noise ratio, quality factor, distance above the FEC limit | [04](04_repeater_and_optics.md) |
| **PFE** | power feed equipment | [02](02_power_feeding.md) |
| **Provenance** | a parameter's unit, status and source | [07](07_parameters_and_provenance.md) |
| **Regulator time constant `tau`** | how fast the PFE corrects a current error (5 ms here) | [03](03_circuit_model.md) |
| **Relock** | the receiver finding the signal again after an outage | [05](05_terminal_and_traffic.md) |
| **Repeater** | a box every 60 km that amplifies the light, powered by the line current | [04](04_repeater_and_optics.md) |
| **Sea earth / station earth** | the PFE's two earth paths; the model uses one, 3 ohm | [02](02_power_feeding.md) |
| **Zener stack** | the repeater's nearly constant-voltage shunt, about 56 V | [13](13_zener_protection.md) |
